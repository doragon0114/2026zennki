■ キャラクター画像の差し替え方法

このフォルダに、以下のファイル名でPNG画像を置くだけで、
ゲーム内のキャラクターがその画像に自動で切り替わります。
（画像が無いキャラは、いままで通りのドット絵で表示されます）

  hero.png   … 勇者（戦闘画面・マップ・タイトル）
  king.png   … 王様の顔（メッセージ横の顔グラフィック）
  slimeA.png … スライム（はじまりの草原の敵）
  slimeB.png … ぶるぷるん（港町の敵）
  slimeC.png … デビルスライム（国境の村の敵）
  demon.png  … だてんしデーモン（中ボス）
  maou.png   … まおう ダークロード（ラスボス・タイトル画面にも表示）

■ おすすめの画像形式
  ・背景が透明なPNG（透過PNG）
  ・サイズは自由（枠に合わせて自動で縮小・拡大されます）
    目安: 敵 240×240px前後 ／ 勇者 120×150px前後 ／ 王様 64×64px前後
  ・ドット絵ならくっきり表示、イラストならなめらかに表示されます

画像を置いたら、ブラウザをリロード（再読み込み）してください。
