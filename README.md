## 概要
自分で記録したノートや授業内で配布されたPDFからAIが問題を自動生成し、自分だけの復習問題を生成してくれるWEBアプリRevinoです。　　
対応ファイルは画像・PDF・DOCX(文書ファイル)です。また、スマホでは直接ノートの写真を撮りアップロードしてくれる機能があります。　　
AIの性能上、問題の生成に時間がかかる為、休み時間や空き時間に授業資料をアップロードし、別の空き時間で個人演習や対戦機能などをご使用いただけるとスムーズに使えます。

問題生成以外にも、個人演習・対戦機能・RPG機能・パズルルーム(未実装)・成長機能といった勉強＋ゲーミフィケーション要素を兼ね備えています。　　

個人演習：生成した問題をひたすら解いていく　　
対戦機能：生成した問題を使って他利用者とクイズ形式の対戦が出来る
RPG機能：モンスターが生成した問題を使ってクイズを出してくる、最終目標の魔王を倒すためにRPGの冒険に出てもらう　　
パズルルーム：共有した問題を解いていくごとにパズルが埋まっていき完成するとコレクションが増えていく
成長機能：学習回数や対戦勝利数などに応じてキャラクターが成長していく

## 注意点
問題生成AIとしてOllamaの使用およびqwen2.5:3bを使用しています。
Qwen2.5:3b以外のAIを使用したいと考えている場合はコマンド以外にもバックエンド側のAIを指定しているコードを書き換えないといけません。

## 環境
Node.js + MySQL + Ollama のDocker環境を構築しました
- Node.js 20
- MySQL 8.0
- Ollama (qwen2.5:3b)

## 以下起動手順
1. `.env` ファイルを作成（内容のAPIキーはテンプレートを編集して別途個人で用意してもらう）
2. `docker-compose up --build` を実行
3. `docker compose exec ollama ollama pull qwen2.5:3b`を実行
4. `http://localhost:3000` にアクセス
5.` docker compose exec mysql bash` でMysqlコンテナーに入った後
Mysqlにログインしてもらい(.envのアカウントを入れてもらう)、RevinoDB.sqlをコピペして実行する
